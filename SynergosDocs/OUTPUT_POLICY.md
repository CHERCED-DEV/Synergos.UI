# Output Policy

## Artifact Lifecycle

Every artifact in the workspace falls into one of three categories:

| Category | Location | Lifecycle | gitignored |
|----------|----------|-----------|------------|
| **Ephemeral build** | `platforms/*/dist/` | Generated at build, published to CDN, cleaned | Yes |
| **Internal lib** | `platforms/angular/dist/libs/` | Generated by ng-packagr, consumed at build time | Yes |
| **Published CDN** | `C:\LOCAL_CDN\synergos\` | Final destination, served to CMS | N/A (external) |

### Key rule

`dist/` is **never** the final destination for elements. The CDN is.

---

## What generates where

### Element builds

```
npm run build
  → platforms/angular/dist/<element>/browser/main.js   (Angular)
  → platforms/react/dist/<element>/main.js             (React)
  → platforms/svelte/dist/<element>/main.js            (Svelte)
  → platforms/vanilla/dist/<element>/main.js           (Vanilla)
```

### CDN publish

```
node tools/publish.mjs --version 1.2.3
  → C:\LOCAL_CDN\synergos\<element>\<framework>\1.2.3\main.js       ← exact, immutable
  → C:\LOCAL_CDN\synergos\<element>\<framework>\1.2.3\manifest.json
  → C:\LOCAL_CDN\synergos\<element>\<framework>\v1\main.js          ← major-pinned (updated each patch)
  → C:\LOCAL_CDN\synergos\<element>\<framework>\v1\manifest.json
  → C:\LOCAL_CDN\synergos\<element>\<framework>\latest\main.js      ← always newest release
  → C:\LOCAL_CDN\synergos\<element>\<framework>\latest\manifest.json
  → C:\LOCAL_CDN\synergos\registry.json                             ← global index with version history
```

### Cleanup

```
node tools/clean-dist.mjs
  → Removes platforms/*/dist/<element>/ directories
  → Preserves platforms/angular/dist/libs/ (ng-packagr output)
```

## manifest.json Schema

Every `main.js` has a co-located `manifest.json` that declares the element's public API:

```json
{
  "tag":         "synergos-hero",
  "alias":       "elementCompHero",
  "framework":   "angular",
  "version":     "1.2.3",
  "tier":        "module",
  "entryScript": "main.js",
  "inputs": [
    { "name": "headingText", "type": "string", "required": false, "default": "" },
    { "name": "variant",     "type": "string", "required": false, "default": "default" }
  ]
}
```

Input descriptors are declared in `vitals/contracts/src/element-inputs.json`.  
Full contract documentation: [ELEMENT_CONTRACT.md](./ELEMENT_CONTRACT.md)

## Versioning Policy

### Version slot purposes

| Slot | Path | Purpose | Who uses it |
|------|------|---------|-------------|
| Exact semver | `/{semver}/` | Immutable audit trail | Debugging, rollback reference |
| Major-pinned | `/v{major}/` | Stable for production | Umbraco production templates |
| Latest | `/latest/` | Always newest | Staging, development, previews |

### What constitutes a breaking change (→ major bump)

- Removing an input
- Renaming an input
- Changing an input's `type`
- Changing an input from optional to `required: true`

### Non-breaking changes (minor or patch)

- Adding a new optional input
- Fixing a rendering bug
- Changing a default value
- Adding a new `variant` or `theme` value
- Performance improvements

### Umbraco template recommendation

```html
<!-- Production: pin to major — safe from breaking changes -->
<script src="/synergos/hero/angular/v1/main.js" defer></script>

<!-- Staging: latest — always picks up newest changes -->
<script src="/synergos/hero/angular/latest/main.js" defer></script>
```

## CDN Path Configuration

The CDN root defaults to `C:\LOCAL_CDN` but can be overridden:

```bash
# Environment variable
export SYNERGOS_CDN=D:\MyCDN

# CLI flag
node tools/publish.mjs --cdn D:\MyCDN
```

## Release Workflow

The `npm run release` command performs the full cycle:

```
build all → publish to CDN (all 3 version slots) → clean element dists
```

This ensures the workspace stays clean after publishing.  
See [BUILD_PIPELINE.md](BUILD_PIPELINE.md) for detailed commands.

## Gitignored Artifacts

These are all gitignored and regenerated automatically:

| Path | Purpose |
|------|---------|
| `**/dist/` | Build output (ephemeral) |
| `**/node_modules/` | Dependencies (per-platform) |
| `**/.nx/cache/` | Nx computation cache |
| `**/.nx/workspace-data/` | Nx project graph cache |
| `**/coverage/` | Test coverage reports |
| `**/.angular/` | Angular compiler cache |

## Antipatterns to avoid

| Antipattern | Why it's wrong |
|-------------|----------------|
| Committing `dist/` to git | Binaries in git history; merge conflicts |
| Writing to CDN without `publish.mjs` | Bypasses versioning, manifest generation, registry update |
| Overwriting an exact semver slot | Semver slots are immutable audit trails |
| Serving elements directly from `dist/` in production | Not versioned; breaks on next build |
| Mixing build artifacts across frameworks in one directory | Impossible to clean selectively |
