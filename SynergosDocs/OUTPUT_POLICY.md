# Output Policy

## Artifact Lifecycle

Every artifact in the workspace falls into one of three categories:

| Category | Location | Lifecycle | gitignored |
|----------|----------|-----------|------------|
| **Ephemeral build** | `platforms/*/dist/` | Generated at build, published to CDN, cleaned | Yes |
| **Internal lib** | `platforms/angular/dist/libs/` | Generated by ng-packagr, consumed at build time | Yes |
| **Published** | `C:\LOCAL_CDN\synergos\` | Final destination, served to CMS | N/A (external) |

### Key rule

`dist/` is **never** the final destination for elements. The CDN is.

---

## What generates where

### Element builds

```
npm run build
  → platforms/angular/dist/<element>/browser/main.js   (Angular)
  → platforms/react/dist/<element>/main.js             (React)
  → platforms/svelte/dist/<element>/main.js            (Svelte)
  → platforms/vanilla/dist/<element>/main.js           (Vanilla)
```

### CDN publish

```
node tools/publish.mjs
  → C:\LOCAL_CDN\synergos\<element>\<framework>\latest\main.js
  → C:\LOCAL_CDN\synergos\<element>\<framework>\latest\manifest.json
  → C:\LOCAL_CDN\synergos\registry.json
```

### Cleanup

```
node tools/clean-dist.mjs
  → Removes platforms/*/dist/<element>/ directories
  → Preserves platforms/angular/dist/libs/ (ng-packagr output)
```

## CDN Structure

```
C:\LOCAL_CDN\synergos\
├── hero\
│   ├── angular\latest\main.js
│   ├── react\latest\main.js
│   └── svelte\latest\main.js
├── pricing-card\
│   └── react\latest\main.js
├── accordion\
│   └── svelte\latest\main.js
├── hello-world\
│   └── vanilla\latest\main.js
└── registry.json                  ← Global index of all published bundles
```

Each element/framework combination gets its own `manifest.json`:

```json
{
  "alias": "elementCompHero",
  "tag": "synergos-hero",
  "framework": "angular",
  "entryScript": "main.js",
  "version": "0.1.0"
}
```

## CDN Path Configuration

The CDN root defaults to `C:\LOCAL_CDN` but can be overridden:

```bash
# Environment variable
export SYNERGOS_CDN=D:\MyCDN

# CLI flag
node tools/publish.mjs --cdn D:\MyCDN
```

---

## Release Workflow

The `npm run release` command performs the full cycle:

```
build all → publish to CDN → clean element dists
```

This ensures the workspace stays clean after publishing. See [BUILD_PIPELINE.md](BUILD_PIPELINE.md) for detailed commands.

## Gitignored Artifacts

These are all gitignored and regenerated automatically:

| Path | Purpose |
|------|---------|
| `**/dist/` | Build output (ephemeral) |
| `**/node_modules/` | Dependencies (per-platform) |
| `**/.nx/cache/` | Nx computation cache |
| `**/.nx/workspace-data/` | Nx project graph cache |
| `**/coverage/` | Test coverage reports |
| `**/.angular/` | Angular compiler cache |
